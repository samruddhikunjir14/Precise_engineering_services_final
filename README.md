# Precise Engineering Services

GitHub Pages-ready static website.

## Files
- `index.html`
- `assets/hero-facade.jpg`

## GitHub Pages
Upload the files to a repository, then go to **Settings → Pages → Deploy from a branch → main → /root**.

The contact form uses `mailto:` and WhatsApp click-to-chat, so no backend is required.

The portfolio uses the six drawing image URLs from the provided project. For a fully self-contained site, download those six JPGs into `assets/` and change the image URLs in `index.html` to local paths.
